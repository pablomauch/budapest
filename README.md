# Budapest a pie · Audioguía

Planificador de 3 días con fichas de lugares (día, noche, comida), recorrido ordenado por cercanía desde tu ubicación, mapa, GPS y narración por voz con historias y leyendas.

Abrir: https://pablomauch.github.io/budapest/

Para editar: cambiá los archivos de `src/` y corré `python3 build.py`.
